# storageprims-core

Provider-neutral traits, types, errors, URI parsing, and capability definitions
for the `storageprims` cloud storage workspace.

This crate is the shared contract used by provider adapters and higher-level
operations. See the [storageprims repository](https://github.com/3leaps/storageprims)
for workspace documentation, and
[how the libraries fit together](https://github.com/3leaps/storageprims/blob/main/docs/guides/how-the-libraries-fit.md) for the provider
contract, optional capabilities, errors, and commit knowledge.
